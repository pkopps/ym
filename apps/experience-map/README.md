# YardMatch experience map

This is a local developer viewer for the website and iPhone app paths. It is separate from the customer product and uses no subscription or public tunnel. The current capture pass covers web, customer iPhone, and part of crew iPhone. Provider iPhone tabs and any uncaptured crew screens remain visible as labeled placeholders until those apps are revisited.

## Run

```sh
npm install
npm run experience-map:refresh
npm run dev:experience-map
```

Open `http://127.0.0.1:4173`. Search for a screen or route, filter by area or screen type, collapse an area with its minus button, select a card to see its incoming and outgoing actions, and open the image for a larger view. Solid links have a matching Playwright workflow test. Dashed links come from UI code. Selecting a card highlights its downstream path. The viewer keeps missing captures as labeled placeholders.

The refresh command discovers every `apps/web/src/app/**/page.tsx` route and every auth/tab screen in the three mobile navigators, merges the curated workflow states in `scripts/experience-map/definitions.mjs`, captures web pages with synthetic in-memory API accounts, runs the customer and crew iPhone Maestro flows, validates endpoints, and writes `data/inventory.json`. Use `npm run experience-map:refresh -- --no-capture` to update inventory quickly while editing graph definitions. `npm run experience-map:validate` checks route and screen coverage, edge endpoints, evidence source files, and missing screenshots.

Compressed WebP thumbnails in `public/captures/thumbnails/` and `captures/manifest.json` are versioned. Full PNG files, synthetic fixture credentials, and Maestro output under `public/captures/full/` stay local. The viewer falls back to a thumbnail when a full PNG is absent. Five Playwright screenshot artifacts used for representative workflow states are imported during refresh when present; they are labeled `test capture`.

For iPhone captures, install the free Maestro CLI, Xcode, and an iOS simulator. The capture script boots or uses a simulator, builds the selected apps when needed, and runs scripted auth and tab flows with synthetic credentials generated by the web pass. Set `EXPERIENCE_MAP_SIMULATOR_ID` to choose a device. The default app list is `customer,crew`; set `EXPERIENCE_MAP_APPS=customer,provider,crew` when provider capture resumes. Set `EXPERIENCE_MAP_REBUILD_MOBILE=1` to rebuild installed simulator apps after source changes. If a native app, simulator, or API is unavailable, refresh reports the missing screenshots and preserves labeled placeholders. See [Maestro installation](https://docs.maestro.dev/maestro-cli/how-to-install-maestro-cli) and [screenshot command](https://docs.maestro.dev/reference/commands-available/takescreenshot).

Curated edge definitions belong in `scripts/experience-map/definitions.mjs`. Add a UI source path or a Playwright test path for each action. Do not connect web and native apps unless a real deep link or navigation action exists. Locale variants share the same path node; English is the first capture language.
